Funding Request Statistics — bar-chart prototypes

A — current two-panel bars (baseline)

Each measure its own panel over the shared label axis. What the page shows today.

B — value labels at bar tips + formatted ticks

Same two-panel layout, numbers printed at each bar end; axis ticks shortened (50k, 100k). No cross-referencing the axis needed. Drop-in change to _bars_figure.

+ every value readable without tracing gridlines  ·  same layout as today

− labels need headroom (x-range padded ~18%)  ·  two axes still read as two charts

C — single spend panel, publications annotated inside the bar

Spend is the headline measure; the publication count rides along as white text inside the bar. One axis, full width, longest labels get the most room.

+ half the vertical space per figure  ·  spend comparison is dead easy

− publications lose their own scale (annotation only)  ·  tiny rows can't fit the text (fallback: outside)

D — stacked spend composition

Spend split per row into contract / APC / book fees. Answers "where does the money go" per institution — a question no current view can answer.

+ new information per row  ·  still exact totals (segments sum to the bar)

− needs a split measure in RequestFact (dataset.py + dto change)  ·  segment comparison across rows is hard (stacked, not grouped)

E — spend panel with labels + small publications strip

C's single spend panel, plus a thin publications bar strip underneath sharing the same rows — publications keep their own scale, labels stay readable.

+ both measures keep exact, labeled values  ·  compact two-row figure

− tallest/complex figure of the set  ·  needs two y-axes mirrored
